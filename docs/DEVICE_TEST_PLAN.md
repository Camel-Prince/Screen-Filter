## 小红书不遮挡的定位顺序

1. 本地路径：点首页「添加测试词」，保存并开启；进入含「秋招」或「考研」字样的帖子，收起键盘。确认标题是否可遮挡。
2. 云端路径：确认首页「云端图文：已启用」，模型内置图测试通过；停在相关帖子10–15秒。
3. 返回首页复制诊断。截图尝试为0看目标窗口原因；尝试>0成功0看截图错误；已发>0返回0看网络或作废；返回>0采用0看页面变化/复核；采用>0命中0才有证据进一步查模型规则与漏判。
4. 诊断不含截图与密钥。若需要内容样本，再由用户主动提供已去除个人信息的帖子截图；不自动记录页面。
5. 对照无变化但频繁刷新通知、顶部轮播变化、滚动换帖、纯图片换图；普通模式已命中区域应允许其他区域变化，先遮后审的整图变化仍须重判。

## 模型日志验收

1. 覆盖安装后，首页和模型配置页均能进入「模型运行日志」；尚无请求时可见实时开关/权限状态，不显示虚构识别结果。
2. 做内置图连接测试，查看同一编号下模型名、主机、图像尺寸、发送、HTTP、解析命中、测试通过或未通过及耗时；复制最近一次识别应包括整个流程。
3. 在小红书静止页面、滚动中、键盘打开时分别观察。请求失败或被取消时有原因，零命中与未请求可区分。回到日志页不会把最近一次识别替换成纯运行状态记录。
4. 默认原始回复开关关闭，不含规则正文、API Key、截图或帖子正文。主动确认开启后再测试，才能看到后续服务回复；复制包含原始回复的记录时会提示个人信息风险。
5. 关闭原始回复后新请求不再记录正文，旧正文仍可见，点击清空才删除。开启日志开关不应修改过滤规则或重启识别服务。
6. 退出并重开 App，历史日志保留；清空后重开仍无旧记录。在请求中清空，迟到回复不得重新写回该旧请求；新的请求可正常记录。
7. 长时间运行日志自动淘汰旧事件；页面显示存储失败时不能宣称已落盘。检查日志页面复制出的信息后再分享，勿提供 API Key。
