## 量化指标

用独立、经授权的屏幕录像或外部相机测量（应用本身不存截图）：

1. 从关键词首次可见到遮挡完成的时间，记录中位数和 P95。
2. 命中样本漏遮率、无关样本误遮率；至少各 30 张真实卡片，OCR 与节点路径分别统计。
3. 滚动期间内容露出时长与错位持续时间。
4. 系统输入事件能否正常穿过遮罩；遮挡不能替代禁用点击。
5. 开启前后的耗电和 CPU 使用变化，固定亮度、网络和滚动轨迹。

发现坐标问题时优先检查窗口截图是否带内边距、系统缩放和无障碍放大；不要通过扩大整屏遮罩掩盖问题。
