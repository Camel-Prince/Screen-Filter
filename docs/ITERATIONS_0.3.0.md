# 0.3.0 三轮实现与检查

日期：2026-09-26。依据：用户的 0.2.0 真机反馈及本地源代码。以下是开发迭代，不是三轮真机或模型效果实验。

## 第一轮：权限和遮挡行为

旧代码每次目标 App 内容/滚动事件都先把遮挡列表设空，然后等待重读；异步结果作废与可见图层清空耦合。旧窗口使用 NOT_TOUCHABLE，点击穿透是代码原有行为。

修改：先计算新文字区域，再更新窗口；去掉事件里的空帧发布。独立区域窗口消费触摸，未遮挡区域保持可操作；优先尝试服务详情深链并显示厂商回退路径。编译、原有15项测试和 Lint 通过。

限制：无障碍通知可能晚于屏幕绘制，不能承诺首帧遮挡；遮挡内部无法起手滑动。权限页直达由手机系统支持程度决定。

## 第二轮：图文判断与状态隔离

新增通义千问配置、加密 Key、显式上传授权、内置图片连通测试、严格矩形响应协议及三种本地安慰主题。快路径仍是本地关键词，图文判断在后台单请求处理；页面版本用于拒绝迟到回答，唯一文字锚点用于跟随已判定区域。旧系统截图保留遮挡并涂灰，独立窗口截图仅 API 34+ 可用。

补充15项测试后30项通过：非法/截断响应、坐标、HTTPS地址、图文负载、主题约束、慢请求/暂停/旧帧、跟踪歧义、重复命中、裁剪后反向滚动。修正了旧系统截图裁剪坐标，以及遮挡出屏后永久缩小的问题。

限制：无文字锚点的内容变化后必须重新判断；云端定位仍可能错误，API 30–33 不提供先遮后审。没有密钥，未进行真实模型准确率或延迟测量。

## 第三轮：跨窗口、隐私和交付检查

检查点击遮挡后活动窗口可能变成自身遮挡的情况，改为优先读取保持焦点的应用窗口，避免点遮挡反而清掉遮挡。回包时重读文字结构；App切换不重置请求最短间隔。系统异常可能包含请求头，因此界面只显示受控错误文本。禁止重定向转发密钥；截图在内存中裁剪、涂灰，密钥不进入日志、自动填充或页面恢复状态。

最终重新构建、执行测试/Lint、校验包名/版本/签名及 ZIP 内 APK，结果记录在 BUILD_VERIFICATION.md。华为截图能力、窗口坐标、拦截触摸和云端实际表现仍须手机验收。

## 设计取舍与对照实验

参考算法设计思路库的 P004（分别控制更新与失效）及 P007（互补路径），作为跨域设计假设，不是移动端性能证据：

| 优先级 | 方案与机制 | 代价/失效边界 | 最小对照 |
|---|---|---|---|
| 1 | 本地坐标完整计算后更新；异步作废不先清空图层（P004） | 仍受系统事件延迟影响 | 同一滑动录像比较旧版与新版露出帧数、错位时长 |
| 2 | 本地词快速命中 + 慢速视觉语义判断（P007）；结果绑定页面版本 | 网络费用、模型误判、无锚点无法连续跟随 | 固定30个图文/语义样本，比较本地-only与混合模式的漏判、等待和请求数 |
| 3 | 支持窗口独立截图时先遮后审，只有有效返回才放行 | 页面等待、阻断操作；旧系统不适用，不保证首帧零曝光 | API 34+ 同样本开关模式，测可见暴露时长与总等待；失败时不得放行 |

第一项应先在用户手机验证，再测试内置图文连接，最后验证真实图文。未将这些实现推断为经过实测的算法收益；本次常规工程咨询不向思路库重复归档。
